# 凌空战甲历史需求总清单与实施验收（2.32）

> 整理日期：2026-07-26  
> 适用环境：Minecraft 1.21.1、Fabric Loader 0.19.3  
> 说明：重复的“继续、开始实现、安装新版”已合并到对应功能项。  
> 状态只表示当前工作树的真实程度：自动测试通过不等于游戏内观感已经验收。

## 状态定义

| 标记 | 含义 |
|---|---|
| ✅ | 已接入正式代码路径并有构建或契约验证；仍可能需要实机观感验收 |
| 🟡 | 已有基础闭环，但与原始要求仍有明显差距 |
| 🔄 | 本轮正在重构或实现 |
| 🐞 | 已定位到现有实现冲突或回归 |
| ❌ | 尚未实现，不能用近似效果冒充完成 |
