# 凌空战甲声音资源来源与许可

`src/main/resources/assets/flight_armor/sounds` 下所有 `.ogg` 均由项目内
`tools/generate_sound_assets.py` 从数学振荡器、程序包络与随机频谱合成生成，
没有读取、混合、重采样或仿制任何第三方音频文件。

- 来源：项目原创程序合成
- 生成参数：48 kHz、单声道、OGG Vorbis
- 随机种子：`0x5A7B0A`，可重复生成
- 许可：与项目根目录 `LICENSE` 相同，采用 CC0 1.0 Universal

若以后加入外部声音，必须在本文档逐项记录文件名、作者、原始链接与许可；
没有明确再分发许可的商业影视、游戏和音效库素材不得进入项目资源。

2026-07-18 的 P2-7/P2-8 第一阶段没有下载或新增外部音频；三型号差异、
水下降高频和真实速度交叉淡化均由运行时混音参数完成，继续复用上述项目原创
OGG，因此许可范围没有变化。
