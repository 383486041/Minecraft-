# 凌空战甲 2.24.0 功能完成度与剩余清单

> 更新日期：2026-07-18
> 判定原则：只把已进入代码、同步与构建门禁的项目记为“代码完成”；真实手感、画面与多人异常仍由游戏内验收决定。

## 1. 本版结论

2.24.0 已关闭上一版清单中的高优先级数据一致性与主要玩法缺口：统一运行快照、B 编队调和、快切恢复、延迟攻击取消、返台、护航恢复、先锋冲撞、真实导弹、破坏性核心束、独立巡航战术、完整度/维修、完整重力冲击、三型号独立模型、3D 物品预览和第一阶段统一声音均已进入代码。

本轮新增的飞行灯光规则：

- 灯光颜色只由观测到的平滑真实位移速度决定，不再由 Ctrl 按键直接跳色。
- Ctrl 只改变推进加速度，速度上升时按青色、蓝色、紫色、品红、橙色、金色连续过渡。
- 松开 Ctrl 或按 S 减速时沿同一曲线反向渐变。
- 胸口棱形核心、面部、装甲纹路、脚底和疾影尾迹共享同一个速度颜色源；所有档位保持高亮。

## 7. 推荐实机验收顺序

1. **灯光与加速：** 悬空按 Ctrl 持续推进，观察速度值平滑上升且所有灯同步逐档变色；松开或按 S 后反向渐变，不能瞬间跳色。
2. **B 编队：** 一个主甲、两个副甲下连续按 B，第二次不得重复脱穿；面板按钮与物理 B 结果相同。
3. **快切恢复：** N 切换的飞离、接近、着装各阶段分别断线/重进；不得复制、吞甲或留下幽灵载体。
4. **返台与重启：** 独立巡航和护航分别回台；远距接近应连续减速，不瞬移；重启后精确恢复同一载体。
5. **战斗：** 先锋冲撞可拉起，疾影导弹可被方块/攻击拦截，守望高充能核心束按规则破坏且遇保护方块停止。
6. **完整度：** 攻击自主战甲至低完整度/失能，确认降级、下落、可召回和平台维修。
7. **重力冲击：** 地面、墙体、实体扫掠和水下四种接触每次俯冲只结算一次。
8. **声音：** 悬浮、缓慢推进、高速/音障、水下和装配的机械层次连续，无 Ctrl 按键触发的尖锐瞬切。

代码门禁通过不等于观感已经“完美”。最终验收仍要求：单人和多人行为一致；断线、死亡、重启、卸载、跨维度和重复输入不复制或吞甲；第一/第三人称不穿模、不遮挡视角；文档、HUD、面板和快捷键一致。
