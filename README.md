# 凌空战甲（Fabric 1.21.1）

一套不依赖鞘翅、烟花或额外加速道具的原创反重力飞行战甲。模型使用独立 OBJ 三角网格、分区发光结构和玩家关节动画，不使用原版方块盔甲外形、喷口或翼装结构。

## 操作速查

> 完整流程图、核心面板示意、状态矩阵和故障排查见 [`docs/OPERATION_GUIDE.md`](docs/OPERATION_GUIDE.md)。

| 操作 | 按键 |
|---|---|
| 启动/关闭悬空 | 穿完整四件或单穿战靴后，双击跳跃键（仅此一义）|
| 高速接地俯冲 | 组合键+双击跳跃键（组合键默认左 <kbd>Alt</kbd>）|
| 悬空移动 | <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd>；跳跃上升，潜行下降 |
| 高速飞行 | <kbd>V</kbd> 切换；视角制导、<kbd>A</kbd>/<kbd>D</kbd> 辅助转向，<kbd>W</kbd> 加速、<kbd>S</kbd> 制动、疾跑键推进 |
| 战甲状态键 | <kbd>B</kbd>，按下方优先级处理 |
| 整套/逐件穿脱 | 组合键+<kbd>B</kbd>、组合键+<kbd>↑</kbd>、组合键+<kbd>↓</kbd>（组合键默认左 <kbd>Alt</kbd>，可在按键设置中重绑） |
| 玩家/指令甲武器 | 未选中指令甲时：<kbd>R</kbd> 腕部脉冲、按住 <kbd>G</kbd> 蓄力核心束；守望超驰形态且僚机完全回收到背甲时，G 联动胸炮与左右翼炮；选中附近巡航甲时：<kbd>R</kbd>/<kbd>G</kbd> 命令该甲攻击准星目标 |
| 手部增强能量光束 | <kbd>Z</kbd>（可在按键设置中重绑）<b>切换</b>「灭世光束模式」，开启后由<b>鼠标左键</b>开火：<b>轻点</b>是点射——冷却仅 2 tick，射击节奏由点击速度决定，不破坏地形；<b>按住约 0.3 秒再松手</b>打出灭世光束，蓄力期间响蓄力循环音、前臂发射器随进度展开。满蓄力射程 150 格、爆坑直径 36 格起（守望型最大 40 格），可把整座山头削平。开启期间左键不再挖掘，HUD 常驻显示当前是哪个键退出 |
| 最近战甲召回 | 组合键+<kbd>R</kbd>（组合键默认左 <kbd>Alt</kbd>）；四槽全空时召回 48 格内最近的己方战甲 |
| 指令甲近战 | <kbd>X</kbd> 切换贴地近战，<kbd>J</kbd> 释放该型号近战大招（<kbd>J</kbd> 仅在遥控模式有效，HUD 模式条会列出）|
| 遥控模式开关 | <kbd>L</kbd>，一键接管或交还最近一套己方战甲，无需打开面板 |
| 护航任务位置 | <kbd>C</kbd>，一键循环全部已加载护航副甲的任务位置：跟随自主 → 贴身跟随 → 原地待命；也可在核心面板的“任务位置”按钮上逐套循环 |
| 守望双形态 | 穿齐同一认主守望套装、且装甲核心在位时按 <kbd>M</kbd>，切换超驰飞行/重装攻坚 |
| 守望僚机 / 独立巡航警戒 | 稳定守望超驰形态下 <kbd>H</kbd> 分离或召回本套僚机；其他情况下切换由身上整甲部署的独立巡航警戒 |
| 核心面板 | <kbd>K</kbd>；手持导航核心右键可激活并直接打开 |
| 核心装备栏 | 背包人物区新增独立核心槽；只接受导航核心；<kbd>K</kbd> 打开当前核心面板 |
| 装甲核心的作用 | 核心在位才解锁**网络能力**：形态切换 <kbd>M</kbd>、遥控指令、编队召回；核心离线时战甲仍可裸装飞行与战斗，只是上述能力锁定。核心在位且穿着胸甲时，玩家胸口会渲染核心挂件 |
| 战甲列表 HUD | 左上角同步当前核心，主甲优先，最多显示四套战甲的主/副身份与实时状态 |
| 单甲状态面板 | 右键完整平台、独立巡航或护航战甲，查看主人、距离、生命周期和冲突；自己的载体可设为指令甲、跟随/待命、召回或切换 |

**`B` 的真实优先级：** 身上四槽为一套完整且身份一致的战甲时，始终先处理这套精确 `suitId`：没有其他独立巡航甲时部署为独立巡航；已有另一套独立巡航甲时则部署为副甲护航，旧甲不被召回或覆盖。四槽仅部分占用时只继续该套分件着装。四槽全空且已有巡航/护航载体时，若背包中存在另一套身份安全的完整战甲，则优先穿戴该本地战甲，场上载体保持原状态；否则再执行当前核心编队、精确召回或普通背包装甲。

- 飞行推进读取可重绑的“疾跑键”；整套/逐件穿脱读取可重绑的“战甲穿脱组合键”（默认左 <kbd>Alt</kbd>）。两者不再共用同一个键，因此急跑/推进与穿脱不会互相误触。若疾跑键与跳跃、潜行或后退键重合，上升/下降/制动优先，不会同时进入虚假的加速状态。
- <kbd>H</kbd> 在稳定守望超驰形态下优先控制本套背甲翼组；其他情况下保留独立巡航警戒语义。它不控制核心副甲；副甲攻击、范围、跟随和返航仍在核心面板设置。
- 右键一套同维度 48 格内的巡航/护航甲后可“设为指令战甲”。即使玩家正穿着另一套战甲，<kbd>R</kbd>/<kbd>G</kbd>/<kbd>X</kbd>/<kbd>J</kbd> 也只路由给所选载体；再次选择同一套会取消遥控并恢复身上战甲按键。服务端会按距离加入约 6～12 tick 的响应时间，每次执行前重新核验主人、`suitId`、精确载体版本、选择会话、维度、距离和目标。上一条远程攻击完成或明确失败前，新按键会收到“正在执行”拒绝，不会静默覆盖已接受的指令。
- 副甲任务位置分三档，按 <kbd>C</kbd> 或核心面板的“任务位置”按钮循环：跟随自主保持编队并按交战规则自主索敌；贴身跟随把编队压到约 1 格并停止主动索敌；原地待命保存独立 HOLD 锚点，不会被核心 FOLLOW 下一 tick 抢回。这三档共用同一个持久化配置，跟随本身仍采用编队、战斗脱离、追赶、失联四层判定并预测主人速度。四槽全空时按组合键 + R 可召回 48 格内唯一最近的己方稳定战甲。
- 多枚核心按各自身份保存独立的平台、主甲和护航配置；换入另一枚核心只切换活动网络，取下后再插回也会恢复原网络。
- 手持当前核心右键属于自己的完整平台可直接绑定；普通方块右键不会切换或清空核心网络。
- 平台不打开容器：<kbd>Shift</kbd>+右键空平台存入身上整套；普通右键完整平台打开状态面板，面板内切换静态陈列；钻石、回响碎片、海洋之心分别重构为先锋、疾影、守望。
- 创造模式物品位于“战斗用品”分页，平台也位于“功能方块”分页。

## 战斗资源与反馈

- 身上战甲以及每套独立巡航/护航战甲都按精确 `owner + suitId + carrier` 拥有独立的能量、热量、阶段、冷却和延迟弹体通道；一套甲蓄力或过热不会锁死其他甲。
- 核心能量上限为 `10000`，普通攻击通常只消耗 `1～15`；守望超驰三炮齐射按蓄力消耗 `12～64`。悬空、飞行、待机和巡航都会快速恢复，正常游玩仍近乎用不完。
- 热量仍为 `0～100` 的瞬时输出限制；达到 100 后武器过热锁定，降到 60 才重新开放，过热不会关闭飞行。
- 能量、热量、过热状态、剩余冷却和左右腕切换由服务端保存，不能通过重登直接刷新。
- HUD 显示能量、热量和冷却；左上角战甲列表每秒从服务端核心快照同步一次，最多显示四套并标记主/副甲与实时状态。攻击姿势、核心/脚底灯光、自定义动态几何光束、导弹轨迹、力场压力环和内外声场均由服务端权威攻击事件驱动。

## 三种战甲型号

- 先锋型：均衡重甲与高碰撞保速；玩家攻击偏范围爆破，护航 AI 偏好高速近身冲撞，未到冲撞窗口时才用腕炮补射。
- 疾影型：最高速度、转向和响应但防御较低；玩家攻击偏连锁/贯穿，护航 AI 会高速环绕并发射最多 6 枚延迟追踪导弹雨。
- 守望型：同一套重装甲拥有两种服务端权威形态。按 M 切到“超驰飞行”后，面甲、胸腰、双臂、膝腿、战靴和背甲共同重排，展开每侧四层的大型机械翼。稳定后按 H，左右僚机直接由各自一侧的真实外翼、翼尖、模块舱和翼炮绕铰链重组并沿弧线离甲；背甲与实体共享同一批 OBJ 几何，交接时没有替代小飞机、透明淡出或整体缩放。再次按 H 会让它们进入捕获走廊、逆向折叠并贴合回背甲。僚机部署时 G 只发胸炮；完全回收后 G 才联动胸炮与双翼炮，满蓄力进入有硬上限和保护规则的毁灭齐射。必须先完成僚机回收，才能按 M 切到“重装攻坚”；该形态将同一批翼片回折为厚重近战轮廓，并解锁专属重型破阵刃与近战招式。
- 只有四件型号完全一致时，才启用对应的完整动力、防御和武器。单穿战靴仍可飞行；混装只按战靴型号使用降级动力。
- 三种型号保留统一速度颜色语义：普通巡航电蓝、`Ctrl` 推进紫→金白、高速飞行橙红→红紫→白热；常态主色只负责辨认型号。
- 型号写入物品 `CUSTOM_DATA`，会跟随玩家、掉落物、巡航载体和充能平台保存；工具提示会显示当前型号。

完整的动力数值、单靴降级档案、三维分区和服务端攻击解析见 `docs/ARMOR_VARIANTS_AND_ATTACKS.md`。

## 被动能力

穿齐同型号整套后，战甲自动提供以下能力，无需按键。破坏地形的部分只在服务端执行，并完全继承核心束的保护规则——`mobGriefing` 关闭、方块实体、`flight_armor:laser_protected` 标签、领地回调、无建造权限或旁观身份都会阻止破坏。

- **撞击爆炸**：高速撞到方块时在撞击点炸开一个球形爆坑，而不是沿运动方向钻一条隧道，也不会被弹开。爆坑半径随**撞击前**的速度增长（上限 9 格）：巡航撞击炸出一个几格的坑，俯冲撞击炸出直径十几格的大坑并掀掉上千块。疾影型能啃下黑曜石，先锋型居中，守望型只能啃软岩。门槛很低（0.05 格/刻），飞着撞就能炸；同一玩家两次爆破之间有 5 刻冷却，避免贴墙斜飞时一秒炸二十次。
- **高速掠过破土**：马赫 1 穿越的冲击波会掀开半径内的方块，半径与预算随马赫数增长（半径上限 12 格、单次上限 320 块）。
- **坠落免疫**：整套着甲时坠落伤害归零。
- **水面滑行**：下半身贴水、头部仍在外时保持高度掠过水面，不下沉也不减速；主动按潜行下潜仍会入水。

## 当前边界

- 玩家主动攻击仍要求完整同型号四件稳定穿戴；单靴和混装只提供飞行动力。
- 副甲可按核心配置攻击关闭、敌对生物或所有合法目标；队友、主人宠物、平台预览和其他战甲载体始终过滤。
- 疾影追踪导弹是服务端实体，会受方块碰撞、寿命、转向和距离限制，也可被攻击摧毁；每枚导弹仍绑定精确 `suitId + carrier + revision`。
- 满足蓄力阈值的玩家核心束可按硬度/方块数预算破坏路径方块；守望超驰齐射为三条独立受保护走廊并在合法命中点触发原版实体爆炸，守望高强度俯冲使用原版方块爆炸。保护方块、方块实体、领地回调和关闭破坏规则会阻止地形改动。撞击爆炸、高速掠过破土与核心束共用同一套破坏护栏（`TerrainDestructionGuard`）；普通腕炮和护航炮击不破坏地形。手部增强能量光束的灭世爆坑同样只经 `ImpactBlastController` 的球形破坏入口，护栏不可绕过；其点射档刻意不破坏地形。
- **高速撞击不减速**：巡航/悬停档撞到方块仍会收速（贴墙不会持续抖动），但高速档撞穿山体时不再套用碰撞速度保留率——否则撞击爆破刚把前方掀开，下一 tick 的计划速度就被削到 0.16 倍，玩家会卡在自己炸出的洞口里。
- 重力冲击支持落地、撞墙、路径实体和水体压力接触；每次高速动作序列只允许提交一次有效冲击。
- 武器与音障特效使用专用动态几何，不调用原版粒子；最终响度、追踪节奏和数值手感仍需在游戏内验收。

历史设计背景可参考 [装甲核心面板与统一控制逻辑评审](docs/装甲核心面板与统一控制逻辑评审.md) 与 [护航战斗与破坏性光束](docs/ESCORT_COMBAT_AND_DESTRUCTIVE_BEAM.md)；完整历史需求、真实完成度与验收条件见 [2.32 历史需求总清单](docs/历史需求总清单与实施验收-2.32.md)，守望基础重构见 [2.33 守望超驰实现说明](docs/守望超驰全身变形僚机联合炮-2.33.md)，实际操作以 2.36 操作手册和当前源码为准。

## 安装

将模组 JAR、对应版本的 Fabric API、Player Animator 和 BendyLib 放入客户端及服务端的 `mods` 文件夹。

## 构建

Windows 开发环境可直接使用项目脚本。默认执行快速增量 remapJar：

~~~powershell
.\tools\build-mod.ps1

# 交付前完整校验
.\tools\build-mod.ps1 -Full

# 构建并安全安装到测试客户端
.\tools\build-mod.ps1 -Install
~~~

脚本默认使用 Java 21 路径和当前 1.21.1 Fabric 测试端，可用 -JavaHome <JDK目录>、-ModsDir <mods目录> 覆盖。安装前会检查 Minecraft 进程及 JAR 锁，旧版备份到测试版本目录下的 _flight_armor_backup，并保证 mods 中只有一个 flight_armor JAR。

产物位于 build/libs。OBJ 资源位于 src/main/resources/assets/flight_armor/models/armor/flight_armor.obj；游戏内可用 F3+T 热重载资源，Java 代码修改后仍需重启客户端。

多核心独立网络、单核心多平台、可见核心装备栏、主/副甲编队调和、返航平台、精确载体遥控和独立战斗 lane 已经实现；当前操作、冲突矩阵和验收项见 [`docs/OPERATION_GUIDE.md`](docs/OPERATION_GUIDE.md) 与 [`docs/2.31-多战甲操作与冲突状态机复审.md`](docs/2.31-多战甲操作与冲突状态机复审.md)。
